# 数据类型 i32 / f64 / bool

Rust 是一门 **静态类型语言**，每个值都有明确的类型，编译器会在编译期检查类型是否匹配。虽然很多情况下类型可以推导，但在函数签名、常量、复杂表达式中，你需要显式写出类型。理解 Rust 的类型系统，是写出高效且安全代码的第一步。

## 引入：类型是数据的身份证 🪪

类型告诉你：

- 这个数据占多少内存？
- 它能参与哪些运算？
- 它可以存储什么范围的值？
- 在函数之间传递时是否需要移动或复制？

Rust 没有隐式类型转换，这让很多潜在错误在编译期就暴露出来。例如，你不能把 `i32` 直接当成 `i64` 使用，必须显式转换。

## 深入讲解

### 标量类型

Rust 有四种标量类型：

- **整数**：`i8` ~ `i128`、`u8` ~ `u128`、`isize`、`usize`。默认整数类型是 `i32`。`isize` 和 `usize` 的大小取决于目标平台（32 位或 64 位），常用于索引和内存大小。
- **浮点**：`f32` 和 `f64`，默认 `f64`。Rust 遵循 IEEE-754 标准。
- **布尔**：`true` / `false`，占用 1 字节。
- **字符**：`char`，4 字节 Unicode 标量值，用单引号 `'🦀'`。

### 复合类型

- **元组 tuple**：固定长度、可以包含不同类型，用 `(1, 2.0, "a")` 表示。可以用模式解构访问元素：

```rust
let tup = (500, 6.4, 1);
let (x, y, z) = tup;
```

- **数组 array**：固定长度、元素类型相同，用 `[1, 2, 3]` 或 `[0; 5]` 表示。数组长度是类型的一部分，不能动态改变。

### 类型标注

```rust
let guess: u32 = "42".parse().expect("Not a number!");
```

如果没有 `: u32`，编译器无法确定 `parse` 要解析成什么类型，会报错。

### 类型转换

Rust 不会自动做类型转换，必须使用 `as` 关键字显式转换：

```rust
let a: i32 = 10;
let b: i64 = a as i64;
```

### 类型别名

使用 `type` 关键字可以给现有类型起别名：

```rust
type Kilometers = i32;
```

## 常见误区 ⚠️

- 用双引号表示字符：`char` 用单引号，`String` / `&str` 用双引号。
- 数组越界访问：`arr[10]` 在 Rust 中运行时会发生 panic，编译期不会报错，但会提示索引类型。
- 整数溢出：在 release 模式下，整数溢出会发生环绕（wrapping），不会 panic；debug 模式会 panic。需要安全处理时应使用 `checked_add` 等方法。
- 把 `f64` 和 `i32` 混用：Rust 不会隐式转换浮点数和整数。

## 一句话总结 ✅

Rust 的静态类型系统让错误尽早暴露；掌握标量、元组、数组、类型标注和显式类型转换，是写出健壮 Rust 代码的基础。
