# Hello World println!

欢迎来到 Rust 学习之旅！🦀 Rust 是一门注重 **安全、并发和性能** 的系统级编程语言。它不像 C/C++ 那样把内存安全完全交给程序员，也不像带垃圾回收的语言那样在运行时承担额外开销，而是通过一套精巧的 **所有权（Ownership）** 系统在编译期就把大多数内存错误消灭掉。对于初学者来说，Rust 的编译器可能是你最好的老师，因为它不仅报错，还会给出非常详细的修改建议。

## 引入：从第一行代码开始

每一个 Rust 程序的入口都是 `main` 函数，程序从这里开始执行。如果你学过 C/C++/Java，这个入口的概念会非常熟悉：操作系统加载程序后，第一个被调用的就是 `main`。

```rust
fn main() {
    println!("Hello, world!");
}
```

这段代码虽然简单，但已经包含了 Rust 的几个核心元素：函数、宏调用和表达式。

## 概念图解 💡

可以把 Rust 程序想象成一座工厂：

- `fn main()` 是大门，所有货物（执行流程）都从这里进出。
- `println!` 是工厂里的广播系统，把信息输出到终端。
- `!` 结尾表示这不是普通函数，而是 **宏（macro）**。

## 深入讲解

### 函数

使用 `fn` 关键字定义函数，`main` 是特殊的主函数。函数体由一系列语句和表达式组成。Rust 的函数签名要求明确参数类型和返回类型，但 `main` 比较特殊，通常不需要写返回类型。

### 宏

以 `!` 结尾的调用，如 `println!`。宏在编译期展开，比普通函数更灵活，可以接受可变参数、做代码生成。`println!` 是最常用的输出宏。

### 语句与表达式

- 大多数以分号 `;` 结尾的是**语句**，不返回值。
- **表达式** 的值会被返回，表达式末尾没有分号。

### 格式化输出

`println!` 是最常用的输出宏，支持占位符格式化：

- `{}` 使用 `Display` trait 格式化
- `{:?}` 使用 `Debug` trait 格式化
- `{:.2}` 可以控制小数位数等精度

Rust 的宏会在编译时检查参数数量和类型，捕获很多运行时错误。

## 运行程序

在终端中可以使用 `rustc main.rs` 编译，然后执行 `./main`，也可以使用 `cargo run` 来编译并运行整个项目。🚀 对于实际项目，推荐始终使用 Cargo，它会自动管理依赖和构建配置。

## 常见误区 ⚠️

- 忘记 `println!` 末尾的 `!`：这是初学者最常见的错误之一。
- 用单引号包裹字符串：Rust 字符串字面量使用双引号 `"..."`。
- 忽略编译器的友好提示：Rust 编译器报错信息非常详细，通常会直接告诉你怎么改。
- 混淆 `print!` 和 `println!`：后者会自动换行。

## 一句话总结 ✅

`main` 是 Rust 程序的入口，`println!` 是宏调用；从第一行代码开始，你就已经接触到了 Rust 函数、宏和表达式这三大核心概念。
