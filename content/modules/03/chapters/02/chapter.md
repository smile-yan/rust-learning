# 所有权：内存管理的哲学 🦀

所有权是 Rust 区别于其他语言的根本设计。它用一套简单的规则，在编译期解决内存安全难题。

## 三条铁律

1. **每个值都有一个所有者**。
2. **同一时间只能有一个所有者**。
3. **所有者离开作用域，值被自动释放**。

这三条规则看起来简单，却足以消除 double-free、use-after-free 和悬空指针。

## 移动而非复制

当把堆上的值赋给另一个变量时，Rust 默认「移动」所有权，而不是深拷贝。这避免了：
- 多个变量指向同一块内存
- 重复释放或遗漏释放

```
let s1 = String::from("hello");
let s2 = s1;       // s1 的所有权移动到 s2
// println!("{}", s1); // ❌ 编译错误
```

## 借用：不转移所有权

如果只是想临时使用值而不想拿走它，就用借用：
- `&T`：不可变借用，可以有多个。
- `&mut T`：可变借用，同时只能有一个。

借用规则保证：
- 不能同时存在可变引用和不可变引用
- 引用不能比被引用的数据活得更久


![借用规则：读可共享，写必独占](images/module3-ownership-borrow.svg)

## 为什么这样设计？

所有权把内存责任写进了类型系统。你不需要记住每个指针该由谁释放，编译器会替你检查。这种「显式责任」的哲学，是 Rust 安全的基础。

## 一句话总结 ✅

所有权让每块内存都有明确的主人；移动和借用规则确保这个主人不会同时有两个，也不会在离开前把钥匙借给别人。
