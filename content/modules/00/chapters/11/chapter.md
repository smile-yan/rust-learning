# 注释与运算符 //

注释让代码更易读，运算符让代码能表达计算和比较。Rust 的注释和运算符与许多 C 风格语言相似，但也有一些独特之处，特别是在文档注释和运算符重载方面。

## 引入：代码是写给人看的 📝

好的注释解释“为什么”，而不是重复“是什么”。Rust 支持普通注释、文档注释，以及用于文档测试的特殊格式。Rust 社区非常重视文档质量，因为 Rust 的文档工具 Rustdoc 非常强大。

## 概念图解 💡

```rust
// 这是单行注释

/*
 * 这是块注释
 */

/// 这是文档注释，会生成文档
/// # 示例
/// ```
/// let x = add(1, 2);
/// ```
```

## 深入讲解

### 注释类型

- `//`：单行注释
- `/* */`：块注释
- `///`：条目文档注释，用于函数、结构体等
- `//!`：模块文档注释，用于模块顶部

### 文档测试

Rustdoc 会自动运行文档注释中的代码示例，确保文档不会过时：

```rust
/// # 示例
/// ```
/// assert_eq!(add(2, 3), 5);
/// ```
```

### 常用运算符

- 算术：`+`、`-`、`*`、`/`、`%`
- 比较：`==`、`!=`、`<`、`>`、`<=`、`>=`
- 逻辑：`&&`、`||`、`!`
- 位运算：`&`、`|`、`^`、`<<`、`>>`
- 赋值：`=`、`*=`、`+=` 等复合赋值

### 特殊运算符

- `..` 和 `..=`：范围运算符，用于循环、切片、模式匹配
- `?`：错误传播运算符（前面章节讲过）
- `.`：访问字段或方法
- `::`：访问关联函数、常量、模块路径

### 运算符重载

Rust 允许为自定义类型实现运算符 trait，例如 `std::ops::Add`。不过初学者不需要急于掌握。


### 运算符优先级

Rust 的运算符优先级与大多数 C 风格语言一致：乘除高于加减，逻辑与 `&&` 高于逻辑或 `||`，一元运算符优先级最高。当不确定时，始终使用括号，这不仅能避免错误，也让代码更易读。

```rust
let a = 1 + 2 * 3;       // 7，乘法优先
let b = (1 + 2) * 3;     // 9，括号改变优先级
let c = true || false && false; // true，&& 高于 ||
```

## 常见误区 ⚠️

- 整数除法截断：`5 / 2` 结果是 `2`，不是 `2.5`。要得到浮点数，需写成 `5.0 / 2.0`。
- 用 `=` 做比较：`if x = 5` 会报错，Rust 不允许赋值表达式作为条件。
- 注释过多或过少：注释应解释意图，而非重复代码。
- 混淆 `//` 和 `///`：后者用于生成文档。

## 一句话总结 ✅

Rust 注释包括普通注释和文档注释；运算符与 C 系语言类似，但要注意整数除法、`=` 与 `==` 的区别，以及文档测试的威力。
