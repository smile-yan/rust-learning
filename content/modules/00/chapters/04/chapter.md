# 函数 fn

函数是 Rust 代码的基本组织单元。Rust 使用 `fn` 关键字声明函数，强调显式参数类型和返回类型。函数也是表达式：如果最后一个表达式不以分号结尾，它的值就是函数的返回值。掌握函数，就掌握了把复杂问题拆分成可维护模块的关键能力。

## 引入：函数是程序的乐高积木 🧱

把复杂问题拆分成小函数，是写出可维护代码的关键。Rust 的函数签名非常清晰，调用方一看就知道需要什么参数、返回什么结果。函数名应该表达其行为，参数名应该表达其含义。

![函数结构示意图](images/module0-functions.svg)

## 概念图解 💡

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b   // 注意：没有分号，这是返回值
}
```

函数签名的四个部分：

- `fn`：声明函数的关键字
- `add`：函数名
- `(a: i32, b: i32)`：参数列表，每个参数都要标注类型
- `-> i32`：返回类型

## 深入讲解

### 参数

Rust 是显式类型语言，函数参数必须写类型。相比动态语言，这看起来繁琐，但能避免大量运行时错误。参数怎么传递（值还是引用）直接影响调用后原变量还能不能用，详见下文。

### 值传递与引用传递

函数参数的传递方式直接决定了调用之后原变量还能不能使用，这是 Rust 新手最容易困惑的地方之一。

**值传递（按值传递）**：把值本身交给函数。

- 对于实现了 `Copy` 的类型（如 `i32`、`bool`、`f64`），传参时会复制一份副本，函数内修改的是副本，原变量不受影响。
- 对于没有实现 `Copy` 的类型（如 `String`、`Vec`），传参会**移动所有权**，调用结束后原变量就失效了，再使用会直接编译报错。

**引用传递（借用）**：把值的引用交给函数，不转移所有权，函数用完即归还。

- `&T`：不可变引用，函数内只能读取，不能修改。
- `&mut T`：可变引用，函数内可以通过 `*` 解引用修改原值；借用结束后原变量继续有效。

```rust
fn plus_one_value(mut x: i32) {  // 值传递：i32 是 Copy 类型，x 只是副本
    x += 1;
    println!("副本加一后: {}", x);
}

fn plus_one_ref(x: &mut i32) {   // 引用传递：借用原值本身
    *x += 1;
}

fn main() {
    let a = 5;
    plus_one_value(a);
    println!("a 仍然是 {}", a);  // 5，原值不变

    let mut b = 5;
    plus_one_ref(&mut b);
    println!("b 变成了 {}", b);  // 6，原值被修改
}
```

经验法则：只想读取数据用 `&T`；需要修改原值用 `&mut T`；确实需要拿走所有权（或类型本身实现了 `Copy`）时才用值传递。

### 返回值

函数可以返回一个值。返回方式有两种：

- 最后一个表达式的值（推荐）
- 使用 `return` 关键字提前返回

```rust
fn square(x: i32) -> i32 {
    x * x
}
```

### 语句与表达式的区别

```rust
fn demo() -> i32 {
    let y = 6;   // 语句，不返回值
    y + 1        // 表达式，返回 7
}
```

如果在 `y + 1` 后面加分号，它就变成了语句，函数会返回 `()`（单元类型），导致类型不匹配。

### 函数作为值

Rust 支持把函数当作值传递（函数指针），也支持闭包（closure）：

```rust
let f: fn(i32) -> i32 = square;
```

## 常见误区 ⚠️

- 在返回表达式末尾加分号。
- 参数不写类型。
- 函数签名写了返回类型，但函数体没有返回对应类型的值。
- 误以为 Rust 函数参数默认是引用传递。

## 一句话总结 ✅

Rust 函数通过显式参数和返回类型保证清晰性；最后一个表达式就是返回值，不要在末尾加分号。
